# Bom Chefe

Jogo pixel art de restaurante, feito com HTML, CSS e JavaScript puro. Não exige servidor, instalação ou conta.

## Como abrir

Abra `index.html` em um navegador moderno.

## Criar um mundo

Na tela inicial, clique em **Criar mundo**, escolha um nome e uma carreira. Cada mundo fica salvo de forma independente no navegador, portanto é possível manter um mundo de cozinheiro e outro de garçom.

## Controles

- **Computador:** setas do teclado para andar e **Espaço** ou **Enter** para interagir.
- **Celular:** botões de direção e botão **AÇÃO**, abaixo do mapa.

## Carreiras

### Cozinheiro

Pegue os ingredientes corretos nas bancadas e use o balcão para entregar o prato. Se o pedido estiver errado ou levar tempo demais, o cliente reclama na cozinha e o jogador perde moedas.

Existe também o **Rarinho**, uma pegadinha especial feita com pimenta mexicana, pimenta indiana e pimenta chinesa. Ao servir o Rarinho, o jogador ganha 3 moedas. O cliente reclama, vai embora e o cozinheiro ri muito, sem perder moedas.

### Garçom

Pegue o prato no balcão e entregue na mesa indicada. Se o personagem carregar um prato e bater em uma mesa, no balcão ou em uma parede, o prato cai no chão e o jogador perde moedas.

### Pimentinha

Pimentinha é o dragão de fogo amigável que recebe as crianças no salão. Cada criança feliz dá uma **estrela de alegria**. Aos sábados e domingos acontece o **Show do Pimentinha**: o jogador vai ao palco e escolhe uma pergunta para uma criança entrevistar o dragão.

O progresso de moedas, pedidos entregues e erros é salvo automaticamente no navegador.
