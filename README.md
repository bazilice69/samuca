# 🏝️ Ilhas Perdidas — A Aventura dos 4

Um jogo de aventura feito por **Samuca**! 🎮

## A história

Um rei malvado separou o mundo inteiro. Quatro pessoas corajosas encontraram
um mundo cheio de ilhas espalhadas pelo oceano. Para voltarem ao seu mundo,
precisam explorar todas as ilhas e **derrotar todos os chefões**!

## Como jogar

1. Clique em **COMEÇAR**
2. Leia a história
3. Crie seu herói: escolha o **nome** e uma das **4 profissões**:
   - 👮 Policial
   - 🚒 Bombeiro
   - 🧑‍⚕️ Médico
   - 🧑‍🍳 Cozinheiro
4. Comece a aventura na ilha inicial!

## Como abrir

É um jogo de navegador (abre no PC e no celular). Basta abrir o arquivo
`index.html` no navegador, ou acessar pela página publicada do GitHub Pages.
